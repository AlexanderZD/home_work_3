# Домашняя работа №3

## Book Scraper: парсинг каталога Books to Scrape
Набор инструментов для извлечения структурированных данных о книгах с сайта `books.toscrape.com`. Проект демонстрирует реализацию парсинга, автоматизации по расписанию и покрытия кода автотестами.

### Цель проекта
Основная цель — создать воспроизводимый пайплайн сбора данных

* **Извлечение данных** Извлечения данных как с одной страници так и из всего католога
* **Автоматизация** Автоматический запуск парсера в определённое время
* **Тест тестирования** Реализация тестов для парсера

### Список используемых библиотек
Библиотеки:
* os
* time
* requests
* schedule
* bs4
